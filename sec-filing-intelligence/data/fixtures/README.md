These are authored, fictional teaching records, not downloaded SEC filings.
Names, amounts, dates, queries, and relevance judgments are synthetic. They
must not be used to infer anything about actual issuers. The fixture JSON
files in this directory are dedicated to the public domain under CC0 1.0:
https://creativecommons.org/publicdomain/zero/1.0/ . Code and documentation
elsewhere are covered by the root MIT license.

Paragraph indices count every nonempty blank-line-separated paragraph,
including headings, starting at zero. Gold labels refer to the exact fixture
text and must be regenerated if that text or the chunking policy changes.
The attack file contains untrusted strings for testing, never instructions
to an application operator. The labels are hand-authored and deliberately
small; they are neither a benchmark nor a held-out SEC evaluation set.
